Hello Kitty Story — Horizontal edition

Open index.html in a browser (or VS Code Live Server).
On mobile: swipe LEFT to go forward and RIGHT to go back.
On desktop: use the mouse wheel or arrow keys.
Each slide snaps into place. The 25 images are in images/01.webp through 25.webp.
Optional music: add audio/music.mp3.
The birthday finale is the last slide.
